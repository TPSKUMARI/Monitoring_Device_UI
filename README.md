# Monitoring Device UI

This project is a simple PyQt5-based desktop interface for a smart monitoring device. It includes a main clock screen, weather information, settings controls, and a voice assistant style screen.

## Project idea

The app simulates a modern device dashboard with:

- Live clock and date display
- Weather information panel
- Active status indicator
- Settings screen for brightness and volume
- Emergency action button
- Voice assistant screen with animated listening effect

## Files

- `ui_designing.py` - Main application code
- `requirements.txt` - Python dependencies

## Requirements

Make sure Python is installed, then install dependencies:

```bash
pip install -r requirements.txt
```

## Run the project

```bash
python ui_designing.py
```

## Controls

- Left / Right / Up / Down arrows: navigate options
- Enter: confirm or activate
- Space: open the voice assistant screen

## Notes

This is a lightweight UI prototype designed to show the concept of a monitoring device interface. It is easy to extend if you want to add more screens, animations, or real device integrations later.
